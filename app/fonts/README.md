# SVN-Uncut Sans

Site font is loaded via `app/fonts.ts` (`next/font/local`).

Replace the `.woff2` files in this folder with your licensed **SVN-Uncut Sans** webfonts from [Font SVN](https://www.fontsvn.com/) (same filenames: Regular / Medium / SemiBold / Bold) when available.

Until then, the committed files are the open **Uncut Sans** family (OFL-1.1), exposed as `SVN-Uncut Sans` for layout parity.
